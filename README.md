## 中文

Dashcam Viewer 下载与历史版本归档，收录 Windows EXE/ZIP、macOS Intel/Apple Silicon DMG 和配套文件。仓库每天检查更新，并把仍可取得的版本归档到 [Releases](../../releases)。

每个 `v<版本>` Release 可能包含：

- `DashcamViewerWin_v<版本>.zip`：Windows 官方原始下载包。
- ZIP 内原样提取的官方 Windows 安装 `exe`。
- `Dashcam_Viewer_v<版本>.dmg`：macOS Intel 版。
- `Dashcam_Viewer_v<版本>_AppleCPU.dmg`：macOS Apple Silicon 版（版本 4 起提供）。
- `SHA256SUMS.txt`：所有资产的 SHA-256。

Release 页面同时收录对应版本的发布日期、New Features、New Camera Supports 和 Bug Fixes。

`support-current` Release 收纳官网当前链接的配套文件，包括用户手册、完整版本历史、Windows 安装说明、EULA、卸载说明、K-Lite Codec Pack 以及 Visiondrive 转换器。

## English

Dashcam Viewer download and historical release archive for the GPS dashcam video player. Includes Windows installer EXE/ZIP, macOS Intel and Apple Silicon DMG, release notes, checksums, and support files. A daily GitHub Actions workflow checks for updates.

Each `v<version>` Release may contain the original Windows ZIP, the installer EXE extracted byte-for-byte from that ZIP, Intel and Apple Silicon macOS DMGs, and `SHA256SUMS.txt`.

Each Release page also includes the corresponding release date, new features, camera support changes, and bug fixes.

The `support-current` Release contains the files currently linked by the official site: the user manual, complete version history, installation/EULA/uninstall documents, the required K-Lite Codec Pack, and the Visiondrive converter.
